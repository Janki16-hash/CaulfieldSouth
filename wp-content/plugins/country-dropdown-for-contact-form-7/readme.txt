== Description ==

**Country Dropdown For Contact Form 7** is a free WordPress plugin that adds a fully functional, flag-enhanced country selector field to any Contact Form 7 form. Instead of asking users to type their country manually — or using a plain unstyled select box — this addon gives you a polished, searchable dropdown complete with national flag icons for every country in the world.

Whether you run an international business, a global e-commerce store, a travel booking site, or any website that needs to collect country information from visitors, this plugin delivers a professional, frictionless experience right out of the box.

= Why Use Country Dropdown For Contact Form 7? =

A plain text input for "Country" leads to messy, inconsistent data — one visitor types "US", another writes "United States", and another enters "America". That makes filtering, exporting, and acting on form data a headache.

This plugin solves that problem entirely. It provides a standardized, searchable dropdown with every country in the world, each displayed alongside its recognizable national flag. Users find and select their country quickly, and you receive clean, consistent data every time.

Setup takes under a minute and works exactly like any native Contact Form 7 field — no coding, no custom CSS, no configuration beyond the built-in tag generator.

= How It Works =

1. Install and activate the plugin (Contact Form 7 must already be active).
2. Open any Contact Form 7 form in your WordPress dashboard.
3. Click **Add Form Tag** and select **Country Dropdown** from the tag list.
4. Configure the field name, ID, class, and default country using the tag generator panel.
5. Click **Insert Tag** to add the tag to your form, then click **Save**.
6. The country dropdown with flags and search instantly appears on your form's front end.

No shortcodes. No manual HTML. No additional configuration needed.

== Installation ==

= Automatic Installation (Recommended) =

1. Make sure **Contact Form 7** is installed and activated on your WordPress site.
2. Go to **Plugins > Add New** in your WordPress admin dashboard.
3. Search for **"Country Dropdown For Contact Form 7"** and click **Install Now**.
4. Click **Activate** once the installation is complete.
5. Open any Contact Form 7 form and use the **Add Form Tag** button to add the country dropdown field.

= Manual Installation =

1. Download the plugin ZIP file from the WordPress plugin directory.
2. Go to **Plugins > Add New > Upload Plugin** in your WordPress dashboard.
3. Choose the downloaded ZIP file and click **Install Now**.
4. Activate the plugin after installation completes.

== Frequently Asked Questions ==

= Does this plugin require Contact Form 7? =

Yes. Contact Form 7 must be installed and activated on your site for this plugin to function. The country dropdown registers itself as a native CF7 form tag type.

= Does the free version include all countries in the world? =

Yes. The plugin ships with a complete, pre-loaded list of every country in the world. No manual entry or third-party data source is needed.

= Are country flag icons available in the free version? =

Yes! Flag icons for all countries are included in the free version at no cost.

= Can users search for their country by typing? =

Yes. The dropdown is fully searchable — users can begin typing any part of a country name to filter the list in real time. Keyboard navigation using the up and down arrow keys is also fully supported.

= Can I pre-select a default country? =

Yes. You can set a default country directly from the Contact Form 7 tag generator settings panel, without writing any code.

= Can I limit the dropdown to show only certain countries? =

Restricting the dropdown to a specific list of countries (whitelist), pinning preferred countries to the top, and hiding specific countries (blacklist) are **Pro version features**. [Upgrade here →](https://topsmodule.com/product/country-dropdown-for-contact-form-7/)

= Is the country dropdown accessible / screen reader friendly? =

Yes. The plugin outputs proper ARIA attributes including `aria-required`, `aria-invalid`, and `aria-describedby` to support screen readers and comply with web accessibility standards.

= Is the dropdown mobile-friendly? =

Yes. The country dropdown is fully responsive and works on all devices including desktops, laptops, tablets, and smartphones.

= Can I add a custom CSS class or ID to the field? =

Yes. The tag generator includes fields for a custom HTML ID and CSS class, which you can use to style or target the field with your own CSS or JavaScript.

= Can I mark the country field as required? =

Yes. The tag generator includes a "Required field" checkbox, just like all other Contact Form 7 field types. Validation and error messages work the same way as native CF7 fields.

= Where can I find documentation and setup guides? =

Full documentation is available at [topsmodule.com](https://topsmodule.com/how-to-create-country-dropdown-for-contact-form-7/). A live demo is also available to see the plugin in action before installing.
